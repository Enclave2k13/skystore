# Проект skystore

## Описание:

Skystore - это интернет-магазин на Django для продажи плагинов и примеров кода. Проект позволяет просматривать каталог товаров и отправлять сообщения через форму обратной связи.

## Возможности:

- Просмотр каталога товаров на главной странице
- Страница с контактной информацией и формой обратной связи
- Отправка сообщений из формы с отображением данных в консоли
- Адаптивный дизайн на Bootstrap 5
- Наследование шаблонов для избежания дублирования кода

## Технологии:

- Python 3.12+
- Django 6.0.4
- Bootstrap 5
- Poetry (управление зависимостями)

## Установка и запуск:

### 1. Клонируйте репозиторий:
```
git clone git@github.com:твой-логин/skystore.git
cd skystore
```
### 2. Установите зависимости:
```
poetry install
```
### 3. Активируйте виртуальное окружение:
```
poetry shell
```
### 4. Выполните миграции:
```
python manage.py migrate
```

## Использование:

1. Запустите приложение:
```
python manage.py runserver
```
2. Откройте в браузере:
   - Главная страница: http://127.0.0.1:8000/
   - Контакты: http://127.0.0.1:8000/contacts/
